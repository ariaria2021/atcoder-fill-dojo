# AtCoder 穴埋め道場

スマホで、AtCoder問題の「解法を組み立てる力」を短時間で練習するためのアプリです。

ABC474 A〜C を題材に、方針・不変条件・計算量を穴埋め形式で復習できます。回答と復習予定はブラウザ内に保存されます。

## Development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

## Testing

このアプリでは、学習フローの中心となる採点、答え合わせ、回答保存、復習記録、問題切替を自動テストします。テストが通ることを、主要な学習体験が壊れていないための公開条件とします。

コードを変更したら、関連するテストを追加または更新し、次を確認してください。

```bash
npm test
npm run build
```

開発中にテストを継続実行するには、次を使います。

```bash
npm run test:watch
```

GitHub PagesのCIは、`npm ci` の後にテストを実行します。テストが失敗した場合はビルド成果物を公開しません。自動テストの対象外であるスマホ幅の見た目や外部リンクは、公開前に手動でも確認します。
